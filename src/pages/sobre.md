O Vox Seas Brasil é um guia independente para quem joga Vox Seas no Roblox. Publicamos em português e inglês.

## Como usar o guia

Se você acabou de chegar a Solmar, comece pelo [guia para iniciantes](/iniciante/). Durante a partida, consulte o [mapa das ilhas](/mapa/) para planejar a viagem ou o [Fruitdex](/frutas/) para comparar habilidades.

## Quem responde pelo conteúdo

A equipe deste site organiza as informações para os jogadores. A Roblox e os desenvolvedores de Vox Seas administram seus próprios serviços. Encontrou um preço, requisito ou código desatualizado? Veja como [pedir uma correção](/contato/).
